Put the contents of the 同級生２ (Taiwan release) CD here: `DATA/`, `MUSIC/`, `SPEECH/`,
`LOGO.AVI`. `nanpa2.exe` is not needed. The save files `FLAG0`..`FLAG6` are optional: the engine
generates a blank one when a slot has none, and the saves of an installed game copied here are used if present.
Nothing in this folder except this file is committed.
